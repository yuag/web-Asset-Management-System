系统设置

FOFA API 配置

配置后域名探索将同时调用 crt.sh 与 FOFA。未配置则仅用 crt.sh。

指纹识别配置

调整指纹识别的并发数、超时时间和批处理大小，优化大量资产的识别速度。

定时自动扫描

启用后每天定时自动扫描所有已添加的根域。

钉钉通知

扫描完成或检测到高危CVE时自动发送钉钉消息。

代理配置

所有外部请求（FOFA、crt.sh、Whois、NVD、Nuclei）将通过代理发送。Nuclei 扫描开始前会自动检测代理连通性与出口 IP。

端口扫描配置（轻量 TCP banner 识别）

新发现的带 IP 资产会自动执行轻量端口探测（纯 Python socket，仅 connect + banner 读取，不发送任何攻击载荷）；也可在资产库手动勾选触发。同一资产 24 小时内自动去重（手动触发忽略）。

AI 模型配置（多模型）

为「🤖 AI助手」提供自然语言能力。启用并填写 API Key 的模型即可在 AI 助手中使用；「⭐ 默认」的模型用于新会话。所有修改在页面底部点击「💾 保存配置」统一生效。

Nuclei 配置

用于对资产执行被动漏洞扫描（Nuclei v3.2+ 支持 -passive，仅运行无攻击性探测模板）。扫描前会自动进行代理与出口 IP 环境检测。
